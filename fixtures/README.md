# Fixtures

Todos los datos de esta carpeta son **ficticios**. No uses datos reales de
personas, empresas, CVs ni ofertas.

- `profile.json`: perfil maestro de ejemplo (Ana Pérez, empresas inventadas).
- `offers/analista-datos-es.md`: oferta en español con un requisito que el
  perfil no tiene (Python).
- `offers/data-analyst-en.md`: oferta en inglés con requisitos que el perfil no
  tiene (Python y Tableau).
- `offers/prompt-injection.md`: oferta con instrucciones ocultas para probar
  que el modelo no las obedece.
- `documents/ana-perez-cv.txt`: CV ficticio de la misma persona, para probar
  la subida y la generación del perfil maestro.
