# Desarrollador Frontend

**Empresa:** Pixel Forge (ficticia)
**Ubicación:** Buenos Aires, Argentina (remoto)
**Modalidad:** Tiempo completo

## Sobre el puesto

Buscamos una persona para construir interfaces claras y accesibles para nuestro
producto de gestión de contenidos. Vas a trabajar con diseño y backend en un
equipo pequeño.

## Responsabilidades

- Desarrollar nuevas pantallas con React y TypeScript.
- Mantener componentes reutilizables y accesibles.
- Escribir tests automatizados para los flujos principales.
- Colaborar con diseño para traducir prototipos en interfaces reales.

## Requisitos

- 2 años o más de experiencia con desarrollo frontend.
- React avanzado.
- TypeScript.
- HTML y CSS.
- Git y trabajo con pull requests.
- Testing de componentes.
- Inglés B2 o superior.

## Beneficios

- Trabajo remoto y horario flexible.
- Presupuesto anual para capacitación.
