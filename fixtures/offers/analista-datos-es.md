# Analista de Datos

**Empresa:** Andes Market (ficticia)
**Ubicación:** Buenos Aires, Argentina (híbrido)
**Modalidad:** Tiempo completo

## Sobre el puesto

Buscamos una persona para sumarse al equipo de Datos y ayudar a convertir
información de ventas y abastecimiento en decisiones concretas. El puesto
reporta a la Gerencia de Operaciones y trabaja junto a Marketing y Finanzas.

## Responsabilidades

- Construir y mantener tableros de ventas y abastecimiento.
- Analizar desvíos contra el objetivo y preparar reportes para la dirección.
- Automatizar reportes recurrentes y documentar los procesos.
- Colaborar con equipos de negocio para definir métricas y prioridades.

## Requisitos

- 3 años o más de experiencia en análisis de datos.
- SQL avanzado.
- Power BI para construcción de tableros.
- Python para automatización de procesos (excluyente).
- Excel avanzado.
- Inglés B2 o superior.
- Buena comunicación escrita y capacidad para explicar datos a personas no
  técnicas.

## Beneficios

- Obra social, vacaciones según convenio y capacitación anual.
- Dos días de trabajo remoto por semana.
